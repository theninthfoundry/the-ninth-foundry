# Portfolio Art Direction Skill (Phase 02.5 — The Beauty of the Unfinished)

Use this skill when making spatial composition, typography, palette, or visual hierarchy decisions for The Ninth Foundry.

## Core Directives
1. **Enforce Controlled Imperfection:** Reject standard grid alignment. Use unequal columns, deliberately off-center focal points, elements overlapping boundaries, and dramatic stretches of negative space.
2. **Treat Typography as a Physical Visual Object:**
   - Display typography (`Instrument Serif`) may intentionally bleed outside the viewport edges.
   - Use contrasting font scales, baseline offsets, and expressive italics to create editorial tension.
3. **Restrain the Opening Viewport:** The Hero must communicate almost exclusively through visual mass, the oversized name, the portrait, and a single restrained identity statement. Defer detailed storytelling to later sections.
4. **Articulate Extreme Sectional Contrast:**
   - *Hero & Collection:* Visually outrageous, visceral, asymmetric, and unexpected.
   - *Selected Work:* Structured, editorial, and technically credible.
   - *The Human:* Quiet, intimate, and biographical.
5. **Manage Tactile Materials:** Pair digital precision with subtle physical artifacts (film grain, fine linework, technical calipers, print misregistration aesthetics).

## Quality Checklist
- [ ] No two consecutive sections share the same spatial composition.
- [ ] The Hero contains zero large introductory paragraphs or skill lists.
- [ ] Visual elements overlap with deliberate depth layers (foreground/background).
- [ ] Negative space is used boldly as an active compositional element, not an accidental gap.
- [ ] Palette remains disciplined: Foundry Black (`#111110`), Archive Paper (`#EAE7DF`), Ivory White (`#F8F7F3`), and selective Signal Red (`#C83D32`).
